# MENU PRO V3 — نسخة البيع للمطاعم

هذه النسخة مصممة كـ Demo تجاري لعرض فكرة المنيو الرقمي على المطاعم.

## أهم المزايا
- تصميم Premium متجاوب للموبايل والكمبيوتر
- Hero احترافي + هوية مطعم
- تصنيفات + بحث
- صور وتفاصيل الأصناف
- عروض خاصة
- سلة كاملة مع زيادة/نقصان الكمية
- بيانات العميل: الاسم، طريقة الاستلام، العنوان/رقم الطاولة، ملاحظات
- إنشاء رسالة طلب مرتبة وإرسالها عبر WhatsApp
- زر QR Code يكوّن QR للرابط الحالي
- قسم "لماذا نحن؟" مناسب للعرض أمام صاحب المطعم
- تخصيص اسم المطعم والعنوان والهاتف وWhatsApp من config.js

## التخصيص السريع
افتح config.js وعدّل:
restaurantName
subtitle
address
phone
whatsapp

## النشر على GitHub Pages
ارفع `index.html` و `config.js` إلى نفس Repository/Branch المستخدم في GitHub Pages.
إذا ظهر تعارض لأن الملفات موجودة، اختر استبدال الملفات القديمة.

## ملاحظة تجارية
الصور والأسماء الحالية Demo. عند التعاقد مع مطعم، استبدلها بصور وبيانات المطعم.

## الخطوة التالية المقترحة
تحويل المشروع إلى نظام متعدد المطاعم:
- رابط مستقل لكل مطعم
- لوحة تحكم لتعديل الأصناف والأسعار
- QR للطاولات
- قاعدة بيانات
- إدارة الطلبات
- دومين خاص للمطعم
