# MENU PRO V2
نسخة Demo تجارية احترافية لمنيو المطاعم.

## التخصيص
افتح config.js وعدّل:
restaurantName
subtitle
address
phone
whatsapp

## النشر
ارفع index.html و config.js إلى نفس مجلد GitHub Pages.

## ملاحظة
الصور الحالية Demo من Unsplash. عند بيع النظام للمطعم استبدلها بصور المطعم.

## المزايا
- تصميم متجاوب للموبايل والكمبيوتر
- بحث وتصنيفات
- تفاصيل الصنف
- سلة طلب
- كميات
- ملاحظات
- حساب الإجمالي
- WhatsApp
- عروض
- بيانات مطعم قابلة للتغيير من config.js

## الخطوة التجارية التالية
ربط QR Code، لوحة تحكم، وقاعدة بيانات حتى تتمكن من إدارة عدة مطاعم من نظام واحد.
